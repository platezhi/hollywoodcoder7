# HollywoodCoder — Studio v2

Сборка 03.11 · 6. Мобильный веб-видеоредактор одним файлом index.html, без сборки и зависимостей.

Сайт: https://platezhi.github.io/hollywoodcoder7/

## Что уже работает
- Проекты в IndexedDB: создание, переключение, импорт и экспорт копии проекта (JSON со встроенными медиа).
- Импорт фото и видео из галереи, ассеты с #тегами и промтом.
- Таймлайн: шкала с делениями, пинч-зум, неподвижный плейхед, выбор клипа, трим за края, разрез, дубль, удаление, ручная длительность.
- Воспроизведение: видео идёт своим ходом, фото держится заданное время; счётчик времени с миллисекундами.
- Отмена последнего действия (до 30 шагов).

## Чего пока нет
- Экспорт готового видео: кнопки нет, рендера нет.
- Veo: кнопка есть, но показывает заглушку «не настроено».
- Аудио, текстовые слои, фильтры, сток-ресурсы.

## Локальный запуск
Открывать через HTTP, а не file://, иначе браузер блокирует IndexedDB:

    python -m http.server 8899
    # затем http://127.0.0.1:8899/
